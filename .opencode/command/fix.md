# Bug Fix

Баг-репорт: **$ARGUMENTS**

## Порядок действий

### 1. Понять баг
- Извлеки из репорта: симптом, шаги воспроизведения, ожидаемое vs фактическое поведение, окружение.
- Если репорт неполный — задай уточняющий вопрос пользователю **до того, как** начинать расследование.

### 2. Воспроизведение
- Попробуй воспроизвести локально (через `bash`, запуск тестов, вызов эндпоинта и т.п.).
- Если нет возможности воспроизвести напрямую — найди релевантный код и трассируй логику вручную.
- Зафиксируй точное условие, при котором баг проявляется.

### 3. Локализация
- Запусти `researcher` через `task`, если нужен широкий поиск по кодовой базе.
- Найди корневую причину: не симптом, а первопричина. Задавай «почему?» пока не дойдёшь до реальной.
- Проверь смежные места — возможно, баг системный и проявляется ещё где-то.

### 4. План исправления
- Сформулируй минимальный патч, решающий корневую причину.
- Определи, какой кодер чинит: `coder-backend` / `coder-frontend` / оба.
- Определи, какой тест закроет регрессию (обязательно) — это делает `coder-tests`.

### 5. Параллельное исправление
Одним сообщением запусти `task` для нужных агентов:
- Кодер-исполнитель (бэк и/или фронт) с точным ТЗ на фикс и указанием корневой причины
- `coder-tests` с ТЗ на регрессионный тест, **который падает до фикса и проходит после**

### 6. Верификация
- Запусти обновлённые тесты, убедись, что зелёные.
- Перезапусти сценарий воспроизведения — баг должен исчезнуть.
- При желании — запусти `reviewer` через `task` для контроля качества фикса.

### 7. Отчёт пользователю
- Корневая причина (в 1–2 предложениях)
- Что изменено: список файлов
- Регрессионный тест: где, что проверяет
- Результат верификации
- Возможные похожие места в коде, которые стоит проверить позже (если нашёл)

## Правила

- **Не маскируй баг.** Исправление должно устранять корневую причину, а не симптом. Если единственный вариант — костыль, явно скажи об этом и объясни почему.
- **Регрессионный тест обязателен.** Без теста фикс считается неполным.
- **Минимальная область изменений.** Не рефактори заодно, если об этом не просили — это отдельная задача.
